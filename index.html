What to check before ordering

Confirm the listing and size

Open the catalog item and check which seller listing it leads to. For shoes, compare your foot length in centimeters with the seller’s chart. For tops, measure a similar garment flat across the chest and from shoulder to hem, then compare the same measurements.

Review warehouse QC photos

If your agent supplies warehouse photos, compare the item label, color, and selected variant with your order. Ask for a ruler photo if fit depends on one measurement. For shoes, check both size labels and ask for an outsole photo if condition matters.

Estimate the delivered cost

Add the item price, domestic delivery, any agent fees, international freight, and applicable import charges. Check whether the carrier bills by actual or dimensional weight. For boxed shoes, compare the estimated parcel dimensions with and without the box.

CSSBuy spreadsheet FAQ

What is a CSSBuy spreadsheet?

It is a product directory or shortlist used to compare seller listings before ordering through a shopping agent. This independent page brings together selected HipobuyFind listings and checks you can apply before ordering.

How do I check whether I can order a find with CSSBuy?

Open the HipobuyFind detail page and locate the original seller URL if one is provided. Paste that URL into your CSSBuy account to check whether the item and variant are supported. Confirm the total and return terms before paying.

What should I do if a listing is missing the size I want?

Note the item ID and check the original seller page for the color and size combination. If the seller has removed that variant or the link no longer works, compare another listing with a clear size chart and current availability.
